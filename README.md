# J.A.R.V.I.S. Bridge — descargas oficiales

© 2026 Santz Programs. Todos los derechos reservados.

Este repositorio solo contiene los **ejecutables publicados** de J.A.R.V.I.S. Bridge (no el código).
El programa necesita una licencia de Santz Programs para funcionar.

- **Instalar:** descarga `JARVIS_Setup_<versión>.exe` de la [última versión](https://github.com/Robotic315/JARVIS-Releases/releases/latest).
- **Actualizar:** usa el botón «⬆ Actualizar» de J.A.R.V.I.S., o ejecuta `JARVIS_Actualizar.exe`
  (siempre sirve el mismo: descarga solo lo que ha cambiado).
